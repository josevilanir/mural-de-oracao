   Change the fetch URL from:
   ```
   /api/upload?contentType=${encodeURIComponent(blob.type)}
   ```
   to:
   ```
   /api/upload?contentType=${encodeURIComponent(blob.type)}&contentLength=${blob.size}
   ```

2. **Update response destructuring:**
   Change from:
   ```typescript
   const { presignedUrl, publicUrl } = await res.json();
   ```
   to:
   ```typescript
   const { url, fields, publicUrl } = await res.json();
   ```

3. **Replace PUT upload with POST FormData upload:**
   Replace the upload fetch block:
   ```typescript
   // OLD (remove):
   const uploadRes = await fetch(presignedUrl, {
     method: "PUT",
     body: blob,
     headers: { "Content-Type": blob.type },
   });

   // NEW (replace with):
   const formData = new FormData();
   Object.entries(fields as Record<string, string>).forEach(([key, value]) => {
     formData.append(key, value);
   });
   formData.append("file", blob);

   const uploadRes = await fetch(url, {
     method: "POST",
     body: formData,
   });
   ```
   IMPORTANT: The `file` field MUST be appended LAST after all policy fields. Do NOT set a Content-Type header — the browser sets the correct multipart/form-data boundary automatically.

4. Keep the rest of the error handling and state management unchanged.
