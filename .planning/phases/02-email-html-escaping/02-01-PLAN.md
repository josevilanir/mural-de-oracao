From lib/email.ts:
```typescript
// Internal helpers (not exported)
function layout(content: string): string  // Wraps content in email chrome
function btn(href: string, label: string): string  // Generates styled button link

// Exported email senders
export async function sendPasswordResetEmail(email: string, token: string): Promise<void>
export async function sendVerificationEmail(email: string, name: string, token: string): Promise<void>
export async function sendCommentNotificationEmail(to: string, authorName: string, commenterName: string, prayerTitle: string, prayerId: string): Promise<void>
export async function sendGroupStatusEmail(to: string, name: string, groupName: string, approved: boolean): Promise<void>
export async function sendJoinRequestStatusEmail(to: string, name: string, groupName: string, approved: boolean): Promise<void>
```

User-controlled parameters requiring escape():
- sendVerificationEmail: `name`
- sendCommentNotificationEmail: `authorName`, `commenterName`, `prayerTitle`
- sendGroupStatusEmail: `name`, `groupName` (only inside layout() HTML, NOT in subject string)
- sendJoinRequestStatusEmail: `name`, `groupName` (only inside layout() HTML, NOT in subject string)

Parameters that must NOT be escaped:
- `token` (server-generated, not user-controlled)
- `email`/`to` (used as recipient address, not interpolated in HTML)
- `prayerId` (used in URL construction only)
- `approved` (boolean)
- `BASE_URL` (server env var)
- `btn()` href argument (URL — escaping would break & query separators)
- `btn()` label argument (always hardcoded string literals in current code)
- Subject line interpolations of `groupName`/`commenterName` (plain-text context — escaping would show literal &amp; entities)
